Okuzukey

Metadata plugin for books, comics, manga and light novels.

Okuzukey always reads local metadata first: NFO files, Calibre metadata.opf, ComicInfo.xml embedded in .cbz/.cbr comic archives, and local cover images. These need no configuration and always take precedence.

Komga

Reads metadata (and, where you have manually corrected it in the Komga web UI, your own corrections) from your own, self-hosted Komga server. Disabled by default; requests are only ever sent to the server URL you enter below.
Without a trailing /api path, e.g. https://komga.example.com:25600 or http://192.168.1.10:25600. Both HTTP and HTTPS are accepted - Komga is commonly run on a local network without a TLS certificate.
Generated in the Komga web UI (My Account → API Keys). Sent as the X-API-Key request header.
Tests the URL, API key and timeout as currently typed in the fields of this section (no need to save first).
Timeout for a single request to the Komga server (1-300, default 30).
How many Komga requests this plugin sends at the same time during a library scan (1-20). Higher values scan faster on a capable Komga server; keep this low (e.g. 1-2) for slow/weak hardware (a Raspberry Pi, say) so Komga isn't overloaded. Default is 4.
Only needed if Emby and Komga see the same library under different paths (e.g. a different drive letter or mount point). Used together with the field below to reliably match an Emby book to the correct Komga book by file path instead of by title. Leave both empty if Emby and Komga already see identical paths.

Logging

How much this plugin writes to Emby's server log. "Verbose" logs a line for every book/comic a local provider looks at (NFO/OPF/ComicInfo.xml/cover readers, plus Komga if enabled), which can add several MB to the log on a large library - use it only while troubleshooting. "Normal" (default) still logs anything that needs attention (warnings, errors). "Nothing" disables even error logging for this plugin.
